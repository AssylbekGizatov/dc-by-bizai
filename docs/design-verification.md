# Проверка интерфейса

> **Историческое свидетельство этапа.** Содержание ниже сохранено для прослеживаемости и относится к проверенному тогда коду. После новых командных изменений актуальны **402 Python-теста (2 skipped), 34 frontend-теста и build** из [DEADLINE_VERIFICATION.md](DEADLINE_VERIFICATION.md). Docker, полный browser E2E и live Groq не повторялись в завершающем прогоне. Старые проверки не складываются с текущей suite и не объявляются заново пройденными.

Проверка выполнена локально 31 октября 2026 года. Данные обращений в браузерных сценариях синтетические. Live-проверка использовала Vite и настоящий FastAPI с авторизацией и SQLite; это не mock API. Генерация в этом прогоне — локальный шаблон, не успешный вызов Groq.

Артефакты до/после, варианты дизайна и JSON детектора хранятся вне Git. В скриншотах live-интерфейса могут присутствовать тексты предоставленных правил, поэтому они не включены в репозиторий или Docker-образ.

После визуального просмотра исправлены два существенных дефекта компоновки: длинные правила перестали отодвигать черновик за первый экран desktop, а на телефоне исходная форма сворачивается после результата. Независимые замечания о потере заметки при отмене эскалации и о повторном входе по прямой ссылке устранены с регрессионными тестами.

Финальная точечная доработка убрала внутренние идентификаторы источников из чтения правил: публичный пункт, название раздела и полный текст сохранены. В очереди появились те же кнопки перехода по разделам, что в анализаторе. На живом API повторно проверены keyboard focus каждого перехода, неизменность маршрута, сохранность набранных черновика и заметки, последующее сохранение и отсутствие горизонтального переполнения на пяти указанных ширинах. Правила остаются раскрытыми: быстрый переход к ответу не скрывает основания проверки. Итоговые desktop/phone снимки просмотрены, ошибок JavaScript не было.
